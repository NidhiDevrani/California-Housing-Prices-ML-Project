# California-Housing-Prices-ML-Project


## Project Overview
This project predicts California house prices using Machine Learning techniques.

The dataset contains information such as:
- median income
- housing median age
- total rooms
- total bedrooms
- population
- households
- latitude
- longitude
- ocean proximity

The target variable is:
- median_house_value

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Data Preprocessing

Steps performed:
- Handled missing values
- Feature scaling
- Train-test split
